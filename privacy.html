Privacy policy

Last updated: 7 November 2026

Studio is a personal dashboard that runs only on its owner's computer and is used only by its owner.

What data Studio accesses

With the owner's permission, Studio reads data about the owner's own YouTube channels through the YouTube Data API and the YouTube Analytics API, using read-only access: channel and video statistics (views, likes, comments, watch time, subscribers) and aggregated, anonymous audience reports (age groups, gender, countries, traffic sources, devices). Studio never reads data about individual viewers.

How the data is used and stored

The data is shown in the owner's dashboard to understand how the videos perform. It is stored only on the owner's own computer. The sign-in token is kept in a local file on that computer.

Sharing

Studio does not sell, share, or transfer any data to anyone, and does not use it for advertising.

Google API Services

Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Studio uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions or through the Google security settings page. Removing it stops all data collection, and the locally stored data can be deleted from the owner's computer.
